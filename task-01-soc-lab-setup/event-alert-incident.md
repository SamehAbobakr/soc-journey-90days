# Event vs Alert vs Incident

## 1. Introduction

Understanding the difference between Log, Event, Alert, and Incident is important for every SOC Analyst.

These terms are related, but they do not mean the same thing.

## 2. Terminology

### Log
A Log is a record that stores information about activities and operations performed by a system, application, or device.

**بالعربي:** سجل يتم فيه تسجيل الأنشطة والعمليات التي تحدث داخل النظام. وقد يكون ملفًا أو مجموعة سجلات.

### Event
An Event is an observable activity or occurrence recorded by a system.

**بالعربي:** حدث أو نشاط حصل داخل النظام وتم تسجيله في الـ Log.

**Windows Event ID Examples:**

| Event ID | Description |
|---|---|
| 4624 | Successful Logon |
| 4625 | Failed Logon |
| 4720 | User Account Created |

### Alert
An Alert is a notification generated by a security tool, such as SIEM, when suspicious activity matches a detection rule or condition.

**بالعربي:** تنبيه يصدر من أداة أمنية عندما تكتشف نشاطًا مشبوهًا.

An alert can be:

- **True Positive:** The alert correctly identifies real malicious activity.
- **False Positive:** The alert incorrectly identifies normal activity as malicious.

### Incident
A Security Incident is an event or group of events that requires investigation and response because it threatens the confidentiality, integrity, or availability of systems or data.

**بالعربي:** حادث أمني يحتاج إلى تحقيق واستجابة بسبب وجود تهديد محتمل أو تأثير على أمن الأنظمة والبيانات.

An incident does not always require confirmed data theft or successful damage.

## 3. Practical Scenario

Imagine an employee account has the following activity:

1. The employee attempts to log in several times using an incorrect password.
2. Windows records these activities in its logs.
3. The failed login attempts appear as Events with ID `4625`.
4. A SIEM detects repeated failed login attempts and generates an Alert.
5. The SOC Analyst performs Triage to investigate the alert.

During Triage, the analyst checks:

- The source IP address.
- The affected user account.
- The time of the login attempts.
- Whether the employee was traveling.
- Whether the successful login was legitimate.

After investigation:

- If the activity is legitimate, the alert may be classified as a False Positive.
- If malicious activity is confirmed or a security incident is identified, the SOC team follows the appropriate response procedures.

## 4. Key Differences

| Term | Meaning | Example |
|---|---|---|
| Log | Recorded information | Authentication log |
| Event | An activity that occurred | Failed login |
| Alert | Security notification | Repeated failed login alert |
| Incident | Security case requiring response | Unauthorized account access |

## 5. My Understanding

A Log stores records of system activities.

An Event is an activity recorded in the Log, such as a successful or failed login.

An Alert is generated by a security tool such as SIEM when suspicious activity is detected.

An Incident is a security case that requires investigation and response.

Before deciding that an alert represents a real security incident, a SOC Analyst should perform Triage and examine the available evidence.

## 6. Important Note

Not every Event generates an Alert, and not every Alert becomes an Incident.

The SOC Analyst must investigate and evaluate the available evidence before making a decision.
